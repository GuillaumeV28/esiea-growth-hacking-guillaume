# Installation — environ 3 minutes

**À l’écran :** GitHub, dossier sujet 8, puis Drive.
« Cet outil transforme mon CV, mes réalisations et une offre en une présentation et une vidéo de candidature. Le rendu est gratuit avec les quotas disponibles. »

**À l’écran :** importer le fichier `Sujet8_Videos_Programmatiques_Guillaume.xlsx`, l’ouvrir, Fichier → Enregistrer au format Google Sheets.
« Je convertis d’abord le classeur Excel en Google Sheets. Je retrouve les trois onglets de contrôle. »

**À l’écran :** Extensions → Apps Script. Montrer `Code.gs`, `Connexions.html`, `appsscript.json`.
« Je copie le code dans Code.gs, je crée un fichier HTML appelé Connexions, et je copie le manifeste. J’exécute installerSujet8, j’autorise les accès Google puis je recharge le tableau. Le menu Vidéos IA apparaît. »

**À l’écran :** paramètres du déploiement, sans les secrets.
« Je déploie l’application Web pour que le moteur local communique avec le tableau. Les demandes sont protégées par un jeton privé. Dans Connexions privées, je configure Gemini et l’adresse du déploiement. Je télécharge le fichier de connexion à côté du moteur, sans le publier. »

**À l’écran :** dossier local, `LANCER.cmd`, puis fenêtre « Moteur prêt ».
« Je lance le moteur. La première ouverture installe ses composants. Je laisse cette fenêtre ouverte : mon ordinateur fait le rendu et dépose automatiquement la vidéo dans Drive. »

# Utilisation — environ 2 minutes

**À l’écran :** trois PDF, ligne PRODUCTION, moteur déjà ouvert.
« Voici mon CV, mon portfolio factuel et l’offre ciblée. Je colle leurs liens dans les trois colonnes et je sélectionne l’option B. »

**À l’écran :** sélectionner une nouvelle ligne, Vidéos IA → Générer la ligne sélectionnée.
« Je déclenche la génération. L’outil extrait les PDF, crée un scénario fondé sur leurs informations et remplit le modèle Google Slides. Une voix synthétique générique présente mon parcours. »

**À l’écran :** montrer les étapes, couper l’attente au montage en l’annonçant.
« Je coupe le temps de traitement dans la vidéo. Le moteur assemble les scènes et les sous-titres, puis envoie automatiquement le MP4 et le GIF dans mon Drive. »

**À l’écran :** statut TERMINE, durée, ouvrir le lien MP4 et lire quelques secondes ; ouvrir Slides.
« La durée mesurée est comprise entre 45 et 60 secondes. Je peux lire le MP4 directement depuis son lien cloud et retrouver la présentation. Les fichiers restent privés. Je relis les affirmations avant de les partager ; aucune candidature n’est envoyée automatiquement. »

Pour la preuve attendue : montrer deux lignes réellement terminées, pas deux lignes remplies à la main. Ne pas filmer la clé Gemini, le jeton ou le fichier de connexion.
