# Vérification réelle — 19 novembre 2026

Le tableau natif et son script sont installés sur le compte Google Guillaume. Le projet Gemini utilisé est celui sans facturation configuré pour les exercices précédents. Les vidéos restent en accès privé.

Deux lignes distinctes ont été déclenchées depuis le menu de Google Sheets, avec des angles éditoriaux différents. La chaîne a extrait les trois PDF privés, appelé Gemini 3.1 Flash-Lite, généré cinq scènes sourcées et une présentation native, produit une voix Windows française générique et assemblé le MP4. Le moteur a envoyé automatiquement le MP4 et le GIF vers Drive et écrit leurs liens et durées dans la Sheet. Aucun réupload manuel après déclenchement.

Un contrôle humain a corrigé l’illustration du modèle, la provenance du poste ciblé et la précision « preuve de concept » pour le projet MCP. Les rendus finaux réutilisent les scénarios déjà générés ; aucune affirmation nouvelle n’a été inventée pour allonger la vidéo.

Les citations proviennent d’un catalogue d’extraits des PDF. Le code vérifie les noms, le poste issu de l’offre, les preuves et les 120 à 145 mots. Un calibrage peut supprimer des phrases complètes. Les durées des pistes réellement produites sont mesurées et ajustées à environ 54 secondes. Les sous-titres suivent les scènes ; leur découpage interne reste estimé.

14 tests techniques locaux réussis : scénario, durée en mots, provenance, références de citations, rejet des fausses promesses, contrôle des URL et refus de l’accès sans jeton. Le moteur Windows et l’installation de ses dépendances ont été exécutés sur la machine. Les deux présentations de cinq pages ont été rendues et contrôlées. Leurs tailles de police natives, parfois inférieures à 12 points dans le modèle pédagogique, ont été conservées ; aucune erreur bloquante du vérificateur de structure.

Limites : ordinateur et moteur à garder ouverts pendant le rendu ; quotas gratuits susceptibles d’erreurs 429/503 ; pas de garantie de fonctionnement permanent. L’OCR est implémenté mais les essais complets utilisent des PDF texte. Pas d’envoi Gmail, de relance, de Calendly ni de Google Vids : le sujet autorise ici Python/FFmpeg. Les tutos Cap restent à enregistrer par Guillaume avec les textes de `TUTOS.md`.

Les rapports, les données personnelles et les URL des vidéos de candidature sont conservés localement dans `Prive_Guillaume/`, hors du dépôt public. Les lignes du tableau font foi pour les dernières URL.
